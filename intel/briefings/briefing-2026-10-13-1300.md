### 1. [CVE-2026-21801] Kubernetes Ingress-Nginx Path Traversal Vulnerability (HIGH)

- **Component:** `ingress-nginx` (Target: `kubernetes`)
- **Base CVSS Score:** `8.4` (`HIGH [P1]`)
- **Published At:** `2026-10-13 10:00:00 UTC`

**Threat Vector & Technical Impact:**
Specially crafted request URI paths in custom snippets allow bypassing URL rewriting rules in ingress-nginx controllers.

**Mitigation & Hardening Playbook:**
Enforce strict URI normalization and upgrade ingress-nginx to v1.11.0 or higher.

### 2. [CVE-2026-20914] Containerd Cgroup v2 Memory Limit Enforcement Race (HIGH)

- **Component:** `containerd` (Target: `kubernetes`)
- **Base CVSS Score:** `7.8` (`HIGH [P1]`)
- **Published At:** `2026-10-13 14:15:00 UTC`

**Threat Vector & Technical Impact:**
Under high concurrency pod creation storms, cgroup memory limits may fail to attach prior to container entrypoint execution.

**Mitigation & Hardening Playbook:**
Update containerd to v1.7.22+ and enable synchronous cgroup driver attachment in CRI config.

### 3. [CVE-2026-19402] NixOS Flake Lock Input Evaluation Hijack (MEDIUM)

- **Component:** `nix` (Target: `nixos`)
- **Base CVSS Score:** `6.1` (`MEDIUM [P2]`)
- **Published At:** `2026-10-13 11:30:00 UTC`

**Threat Vector & Technical Impact:**
Recursive flake evaluations in untrusted git inputs can trigger unintentional remote binary cache fetches.

**Mitigation & Hardening Playbook:**
Enable pure-eval mode and lock input revisions explicitly in flake.lock.

### 4. [CVE-2026-15509] Ceph OSD BlueStore Metadata Desync on Kernel 6.12 (MEDIUM)

- **Component:** `ceph` (Target: `nixos`)
- **Base CVSS Score:** `5.5` (`MEDIUM [P2]`)
