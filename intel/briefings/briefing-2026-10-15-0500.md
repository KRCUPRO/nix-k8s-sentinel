## 🛡️ Active Threat Intelligence Advisories

### 1. [CVE-2026-38102] Kubernetes Kubelet Unauthenticated Remote Execution & Anonymous Access (CRITICAL)

- **Component:** `kubelet` (Target: `kubernetes`)
- **Base CVSS Score:** `9.8` (`CRITICAL [P0]`)
- **Published At:** `2026-10-14 18:00:00 UTC`

**Threat Vector & Technical Impact:**
Deploying Kubernetes worker nodes or control plane services with unhardened flags (--anonymous-auth=true, --authorization-mode=AlwaysAllow, or open --read-only-port) permits unauthorized remote attackers to execute arbitrary container commands or dump cluster secrets via unauthenticated Kubelet endpoints.

**Mitigation & Hardening Playbook:**
Enforce CIS Kubernetes Benchmark Section 1 & 4 controls: set --anonymous-auth=false, --authorization-mode=Webhook, --read-only-port=0, and audit systemd units via nix-k8s-sentinel.

### 2. [CVE-2026-44219] Kubernetes Gateway API & EnvoyFilter Cross-Namespace Route Hijacking & Lua Remote Execution (CRITICAL)

- **Component:** `gateway-api` (Target: `kubernetes`)
- **Base CVSS Score:** `9.6` (`CRITICAL [P0]`)
- **Published At:** `2026-10-15 08:00:00 UTC`

**Threat Vector & Technical Impact:**
Deploying Kubernetes Gateway API routes without cross-namespace ReferenceGrant authorization permits untrusted tenant workloads to hijack privileged backend services, while unanchored EnvoyFilter Lua filter chain injections allow remote code execution or authentication bypass.

**Mitigation & Hardening Playbook:**
Enforce strict Gateway API ReferenceGrant validation, sanitize or disallow dynamic EnvoyFilter Lua script injections, and enforce strict filter chain execution ordering via nix-k8s-sentinel radar.

### 3. [CVE-2026-51204] AMD SEV-SNP & Intel TDX Firmware Measurement Replay & TPM PCR Bypass (CRITICAL)

- **Component:** `amd-sev` (Target: `nixos`)
- **Base CVSS Score:** `9.4` (`CRITICAL [P0]`)
- **Published At:** `2026-10-15 12:00:00 UTC`

**Threat Vector & Technical Impact:**
Unverified remote attestation quotes and desynchronized TPM 2.0 PCR 11 unified kernel image (UKI) measurements allow compromised worker nodes with disabled memory encryption or debug mode enabled to masquerade as verified confidential computing instances.

**Mitigation & Hardening Playbook:**
Enforce TPM 2.0 PCR quotation verification, mandate AMD SEV-SNP/Intel TDX hardware memory encryption in NixOS kernel parameters, and reject attestation tokens with debug mode or expired validity windows.

### 4. [CVE-2026-31048] WireGuard Overlay Subnet Route Collision & World-Readable Key Disclosure (HIGH)

- **Component:** `wireguard` (Target: `nixos`)
- **Base CVSS Score:** `8.5` (`HIGH [P1]`)
- **Published At:** `2026-10-14 08:00:00 UTC`

**Threat Vector & Technical Impact:**
Embedding unencrypted private keys in NixOS configuration files exposes credentials via world-readable /nix/store paths, while unverified allowedIPs subnets permit inter-peer traffic interception.

**Mitigation & Hardening Playbook:**
Migrate private keys to encrypted sops-nix runtime paths (privateKeyFile) and enforce strict allowedIPs CIDR isolation with periodic cryptographic key rotation.

### 6. [CVE-2026-20914] Containerd Cgroup v2 Memory Limit Enforcement Race (HIGH)
