### 1. [CVE-2026-99103] Linux Kernel Privileged Container Escape Bypassing Seccomp via Unconfined Syscall & Missing eBPF LSM Hooks (CRITICAL)

- **Component:** `kernel-lsm` (Target: `nixos`)
- **Base CVSS Score:** `9.8` (`CRITICAL [P0]`)
- **Published At:** `2026-10-17 11:00:00 UTC`

**Threat Vector & Technical Impact:**
Privileged container workloads operating on Linux container hosts lacking declarative eBPF Linux Security Module (LSM) hooks can exploit unconfined kernel syscalls (such as keyctl, io_uring, unshare, or bpf) to bypass user-space seccomp filters, modify host kernel memory structures, and achieve root host execution.
